## Understanding Snapshots

Snapshots are development builds released after each short development cycle, containing bug fixes and new features. These are early-stage versions of the game, not a finished product, so you should expect to encounter bugs, unintended issues, and incomplete features.

## Prerequisites

Before installing a snapshot, make sure you have:
- Downloaded a snapshot file from the [Download snapshots](/en/wiki/download-snapshots) page
- Sufficient disk space to extract the game (minimum 10 GB recommended)
- Permission to run executable files on your computer

## Installation Steps

### Step 1: Extract the File

- Locate the snapshot file you downloaded (usually a .zip or .rar file)
- Choose a location on your computer to extract it (e.g., `C:\Games\CSCDVMP`)
- Right-click the file → **Extract All** (or use extraction software)
- Wait for the extraction process to complete

### Step 2: Launch the Game

- Open the extracted folder
- Find the **cscdvmp.exe** file
- Double-click to run the game

### Step 3: Initial Setup

- The game will launch with the opening screen
- Configure graphics, audio, and control options to your preference
- Save your settings to continue

## Managing Multiple Snapshots

If you want to play multiple snapshot versions:
- Extract each snapshot into separate folders
- Use clear naming (e.g., `CSCDVMP-Snapshot5`, `CSCDVMP-Snapshot4`)
- Each version will store its save data independently
