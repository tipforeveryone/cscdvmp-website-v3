**Date:** March 14, 2026

## New Features

The update introduces tactical coordination enhancements, including a command system that allows players to issue multiple movement orders for individual operators or groups to improve squad efficiency.

A graphics card verification tool now runs on initial launch, helping users avoid rendering issues by ensuring the game uses dedicated graphics hardware rather than integrated alternatives.

Squad composition has been streamlined across briefing and roster screens. Rather than selecting specific operators and weapons individually, "Players now only need to choose a role for each slot, and the game automatically selects an appropriate operator" and corresponding equipment.

Screenshot functionality was added via F11 (including HUD) and F12 (rendered scene only), with files saved to Documents/cscdvmp/screenshots.

## Improvements

Performance and visual quality received significant attention. Updates include engine upgrades, refined anti-aliasing techniques, enhanced reflection rendering, and improved water effects. The lighting system received substantial optimization work, while environment detail and shadow range settings now offer enhanced control for players balancing visual quality with performance.

## Fixes

The patch addressed multiple stability issues, including crashes at match startup and during gameplay, blurry rendering artifacts, and character movement stuttering.
