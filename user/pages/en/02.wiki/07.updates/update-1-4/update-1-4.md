**Date:** May 1, 2026

## Overview

This update introduces significant gameplay enhancements and system improvements to CSCD: Vietnam Mobile Police.

## New Features

**Operator Manager Screen**

A comprehensive interface now displays detailed operator information including personal data, rank, experience points, status, skill progression, and achievement statistics. The system includes 32 unique portrait options randomly assigned upon character creation. Players can access this directly from squad preparation without interrupting workflow.

**Rank & Experience System**

An operator ranking framework has been implemented tied to experience points earned through mission performance. While rank doesn't currently affect gameplay mechanics, the next update will introduce skill point allocation tied to rank progression, directly impacting combat effectiveness.

**Auto Squad Sorting**

A single-button feature enables instant team reorganization by role, prioritizing: "Scout → Assault → Sniper → Engineer → Combat Medic."

**Stance-Based Aim Mechanics**

Crouching significantly reduces arm fatigue during aiming, enabling improved accuracy when combined with breath control techniques.

## Optimization & Bug Fixes

The update enhances rendering efficiency by processing only visible objects, reducing both CPU and GPU strain. Similar optimizations apply to AI and animation systems. Critically, the game now automatically handles save file incompatibilities between versions, eliminating mandatory manual profile deletion. Additional crash-related issues were also resolved.
