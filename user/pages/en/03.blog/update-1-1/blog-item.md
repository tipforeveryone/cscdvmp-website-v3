**Date:** March 14, 2026

## New features

- **Tactical command mode:** Players can issue multiple move commands for individual operators or groups, allowing for faster squad coordination.
- **Initial graphics card check upon first launch:** This helps players verify and select the correct graphics card, preventing rendering artifacts that can occur if the game uses an integrated card instead of a dedicated one.
- **Streamlined squad member selection** for both the map brief and team roster screens: Players now only need to choose a role for each slot, and the game automatically selects an appropriate operator and weapon from the arsenal.
- **Screenshot feature**: Use F11 for screenshots including HUD elements, and F12 for the rendered scene only. All screenshots are saved in the `Documents/cscdvmp/screenshots` folder.

## Improvements

- Latest engine version upgrade.
- Enhanced combination of High Anti-aliasing and Temporal Anti-aliasing (TAA) to avoid blurry artifact upon character movement.
- Improved reflection rendering performance.
- Improved water reflection rendering performance.
- Revamped Environment Detail option: now offers more control over hiding miscellaneous objects to enhance performance.
- Improved Shadow Range option: now with finer control.
- Significantly enhanced lighting system performance.
- Render Quality option now includes extra parameters.

## Fix

- Multiple crashes upon match startup and during certain in-game moments.
- Blurry rendering when High Anti-aliasing and TAA are enabled.
- Stuttering character movement.
