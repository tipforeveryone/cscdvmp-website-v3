## Khái niệm về Snapshots

Snapshot là các phiên bản được tạo ra sau mỗi chu kỳ phát triển ngắn, chứa các bản sửa lỗi và tính năng mới. Đây là những bản phát triển sớm của game, chưa phải là sản phẩm hoàn thiện, do đó bạn nên lường trước việc gặp phải lỗi, vấn đề không mong muốn và những tính năng chưa được hoàn thiện đầy đủ.

## Chuẩn bị

Trước khi cài đặt snapshot, bạn cần:
- Tải xuống file snapshot từ [trang Download snapshots](/vi/wiki/download-snapshots)
- Có đủ dung lượng ổ cứng để giải nén game (tối thiểu 10 GB)
- Quyền truy cập để chạy các tệp thực thi trên máy tính

## Các bước cài đặt

### Bước 1: Giải nén file

- Tìm file snapshot mà bạn đã tải xuống (thường là file .zip hoặc .rar)
- Chọn vị trí trên máy tính để giải nén (ví dụ: `C:\Games\CSCDVMP`)
- Nhấp chuột phải vào file → **Extract All** (hoặc sử dụng phần mềm giải nén)
- Chờ cho đến khi quá trình giải nén hoàn tất

### Bước 2: Chạy game

- Mở thư mục vừa giải nén
- Tìm file **cscdvmp.exe**
- Nhấp đúp vào để chạy game

### Bước 3: Cấu hình ban đầu

- Game sẽ khởi động với màn hình đầu tiên
- Cấu hình các tùy chọn đồ họa, âm thanh và điều khiển theo ý thích
- Lưu cấu hình để tiếp tục

## Quản lý nhiều Snapshots

Nếu bạn muốn chơi nhiều phiên bản snapshots cùng lúc:
- Giải nén mỗi snapshot vào các thư mục riêng biệt
- Đặt tên rõ ràng cho mỗi thư mục (ví dụ: `CSCDVMP-Snapshot5`, `CSCDVMP-Snapshot4`)
- Dữ liệu lưu của mỗi phiên bản sẽ được lưu riêng biệt
