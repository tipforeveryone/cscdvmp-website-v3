Game được phát triển trên nền tảng Titan Engine (tên trước đây là Esenthel) được phát triển bởi Greg Slazinski. Tuy Titan Engine khó có thể vượt qua các engine cao cấp như Unreal Engine hay Unity về nhiều mặt, nhưng bù lại, nó sở hữu những lợi thế đặc biệt, dễ sử dụng với pipeline đơn giản, tốc độ compile cao kết hợp với một IDE mạnh mẽ. Titan Engine rất phù hợp để phát triển các tựa game indie.
